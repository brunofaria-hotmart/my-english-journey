📚 Grammar — Core Tenses

Use this as your main reference. Focus first on the meaning, then the structure.

1. Present Simple

subject + base verb · he/she/it → verb + s

Use: routines, habits, facts, and permanent situations.

I work from home. → Eu trabalho de casa.
She works here. → Ela trabalha aqui.
Do you work here? / Does he work here?
I don't work here. / She doesn't work here.
Important: after does/doesn't, use the base verb: Does she work? ❌ Does she works?

2. Present Continuous

am / is / are + verb-ing

Use: something happening now or a temporary situation.

I am studying English. → Estou estudando inglês.
We are working on a new feature.
Are you working now? / I'm not working now.

3. Past Simple

past verb · questions/negatives → did + base verb

Use: a finished action in the past, especially with a finished time.

I finished the task yesterday.
We deployed it last Friday.
Did you finish the task? / I didn't finish the task.
Rule: did/didn't carries the past: didn't go, not didn't went.

4. Past Continuous

was / were + verb-ing

Use: an action that was in progress at a specific past moment, often interrupted by another action.

I was working at 8 PM.
I was studying when he called.
We were deploying when the pipeline failed.
Compare: I worked yesterday = finished event. / I was working at 8 = action in progress.

5. Present Perfect

have / has + past participle

Use: a past action connected to now, a life experience, or a recent result.

I have finished my work. → Já terminei meu trabalho.
I have been to Canada before.
It has been deployed to production.
Already: I've already finished. / Yet: Have you finished yet? / I haven't finished yet.
Important: ❌ I've finished it yesterday. → ✅ I finished it yesterday. A finished specific time uses Simple Past.

6. Present Perfect Continuous

have / has + been + verb-ing

Use: an activity that started in the past and continues until now, or recently stopped with current relevance. It emphasizes activity/duration.

I have been studying English for two days.
I have been working all morning.
I have been running, so I'm tired.
for = duration: for two hours. since = starting point: since Monday.
Compare: I've studied English for three months = fact/experience. / I've been studying English for three months = activity/duration.

7. Future

There are several natural ways to talk about the future.

will + base verb
Prediction: I think it will rain tomorrow.
Decision now: I'll help you.
Promise: I'll let you know.
am / is / are going to + base verb
Plan/intention: I'm going to study English tonight.
Evidence-based prediction: Look at those clouds. It's going to rain.
am / is / are + verb-ing
Fixed arrangement: I'm meeting my uncle tomorrow.

⚡ Quick Comparison

TenseCore ideaExample
Present Simplefact / routineI work remotely.
Present Continuousnow / temporaryI am working now.
Past Simplefinished past eventI worked yesterday.
Past Continuouspast action in progressI was working at 8.
Present Perfectpast + connection to nowI have finished.

Memory trick: Simple → fact/event · Continuous → activity in progress · Perfect → connection/result · Perfect Continuous → activity + duration

📚 Grammar I’m Learning

Present Simple — do / does

I / you / we / they → do
he / she / it → does
Do you speak English?
Você fala inglês?
Does she work here?
Ela trabalha aqui?
She works here. → In a positive sentence, don't add does.
❌ Does she likes coffee?
✅ Does she like coffee?
After does/doesn't, the main verb returns to the base form.

Present Perfect

have / has + past participle
I've finished my work.
Terminei meu trabalho / agora está terminado.

Use it when a past action has a connection to the present. With a finished past time such as yesterday, Simple Past is normally used:

I finished my work yesterday.

Already vs. Yet

ExpressionMeaningExample
alreadyjáI've already finished.
yetjá / aindaHave you finished yet?
I haven't finished yet.

Present Perfect Continuous

have / has + been + verb-ing
I've been studying English for two days.
Estou estudando inglês há dois dias.

for = duration → for two days. since = starting point → since Monday.

Compare: I've studied English... focuses more on fact/experience; I've been studying English... emphasizes the ongoing activity or duration.

Though

It's expensive. I like it, though.
É caro. Mas eu gosto.
Though it was raining, we went outside.
Embora estivesse chovendo, saímos.
Even though I'm tired, I want to go.
Mesmo estando cansado, quero ir.

Modal verbs

After a modal, use the base verb:

can go · could go · should go · would go · might go · must go
ModalCore ideaExample
canability / permission / possibilityI can help.
couldpast ability / polite request / possibilityCould you help me?
shouldadvice / expectationYou should practice.
wouldhypothetical / polite preferenceI would go if I had time.
mightpossibilityI might go later.
muststrong obligation / deductionHe must be tired.

Perfect modals

modal + have + past participle
  • should have done = deveria ter feito
  • could have done = poderia ter feito
  • would have done = teria feito
  • might have done = talvez tenha feito
  • must have done = deve ter feito

Used to / Be used to / Get used to

StructureMeaningExample
used to + verbcostumava / fazia no passadoI used to live in Brazil.
be used to + noun/-ingestar acostumadoI'm used to working from home.
get used to + noun/-ingse acostumarI'm getting used to speaking English.
Key difference: get used to = process; be used to = state.

✍️ My English Corrections

These are examples of the kind of correction we will keep adding. The goal is natural grammar and sentence structure — not obsessing over capitalization or tiny stylistic details.

Original: I have 3 months in Canada to study english and make my english better to immigration or work for other countries.

Natural: I have three months in Canada to study English and improve my English so I can immigrate or work in other countries.
“improve my English” is more natural than “make my English better”; “immigrate” is the verb; “work in other countries” fits this meaning.
Original: Oops, I canceled without wanted.

Natural: Oops, I canceled it by accident.
After “without,” use -ing: “without wanting to.” “By accident” is the most natural everyday expression here.
Original: docs: update all the documentation from cs hub plataform

Natural: docs: update all CS Hub platform documentation
“documentation for” or “CS Hub platform documentation” is more natural; “documentation” is usually uncountable; platform spelling.
Original: adding management dashboard with ranking graph on health score section

Natural: Adding a Management Dashboard with a ranking graph to the Health Score section.
Singular count nouns need articles: “a Management Dashboard,” “a ranking graph.” We add something “to” a section.
Technical request — natural version:
In the Management Dashboard on the Health Score page, I need to add more graphs, with AM-based data visibility and query parameters. The queries will be executed through Astrobox, so the access control and query parameter handling should be centralized in a separate module. Maybe we can create an Astrobox module in /Users/bruno.faria/Documents/GitHub/api-cs-navigator. This is where my API is located. Then, in the Health Score module, we would only call the Astrobox function and pass the required parameters. Can you send me a plan for how to implement this?
Useful architecture pattern: “Module A handles X. Module B only calls A and passes Y.”
Technical documentation request — natural version:
I need to update all the documentation in this repo: /Users/bruno.faria/Documents/GitHub/cs-messaging-hub. Can you please review the entire project and update all documentation based on the current features and actual implementations? Please make sure the documentation reflects the current codebase, architecture, configuration, workflows, APIs, and infrastructure, and remove or update anything that is outdated.

🎤 Speaking Practice

Because coding and prompting don't always force me to speak, I need deliberate speaking practice.

  1. Pick something I did today.
  2. Speak for 2 minutes without stopping.
  3. Explain a work task in English.
  4. Describe what happened in a real interaction.
  5. Write down 1–3 words/phrases I couldn't express.
  6. Bring them here and ask for correction.
Challenge: Explain your workday using at least one Present Perfect, one Present Perfect Continuous, one phrasal verb, and one modal.
Example: “I've finished my main task, but I've been working on a new feature all morning. I still need to figure out one problem. I might ask a coworker for help.”
